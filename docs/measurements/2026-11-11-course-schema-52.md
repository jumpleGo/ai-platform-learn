## После правки

Один компонент `SiteStructuredData` добавляет Course в исходный граф организации и сайта. Серверный слот Next.js передаёт этот граф в корневой layout; обычный catch-all обновляет его при переходах и убирает Course с других страниц. Тарифы читаются непосредственно из `COURSE_PAYMENT_CONFIGS[slug].tariffs`, без общих тарифов подписки или тестовых цен. Один тариф даёт Offer, несколько — AggregateOffer; нулевые/некорректные цены не публикуются. `isAccessibleForFree` отсутствует.

Техническая метрика: 0/4 → 4/4 проверенных существующих лендингов с Course, совпадающим provider и видимым description. Цены трёх продаваемых программ совпадают с кодом; у `claude-code` offers отсутствует.

Добавлен регрессионный тест, существующие тесты не менялись и не ослаблялись. До реализации четыре проверки упали именно с «Course отсутствует»; после реализации проверяется JSON-парсинг реального SSR-скрипта корневого layout, один граф, единственная организация, provider, обязательные поля, CourseInstance, совпадение описания с DOM, положительные цены, пропуск offers без конфига, один тариф и безопасное экранирование script.

Валидатор `https://validator.schema.org/validate` получил HTML, отрендеренный новым компонентом, для `vibecoding` и `claude-code-agents`. Для обоих: `totalNumErrors=0`, `totalNumWarnings=2`. Оба предупреждения — исходные UNKNOWN_FIELD для `inLanguage` у EducationalOrganization и Organization. У добавленных полей Course/CourseInstance/Offer ошибок нет. Ответы сохранены в `tmp/task-52/*-validator.json`.

Локальный Next.js компилирует структуру маршрутов, но полный HTTP-рендер лендинга упирается в отсутствующий `FIREBASE_SERVICE_ACCOUNT_BASE64`. Секреты и настройки авторизации не менялись. Проверки SSR используют тестовые данные каталога; живой сайт после правки не проверялся, поскольку выкаткой управляет владелец.

Обязательные проверки: `export PATH=$HOME/.local/node/bin:$PATH && npx tsc --noEmit -p . && npx vitest run`.

Результат обязательных проверок: TypeScript exit 0; Vitest — 17 файлов, 142 теста, все прошли. Дополнительный HTTP-запрос к локальной `/guide` подтвердил ровно один исходный граф с организацией и WebSite, без Course. Видимые описания трёх продаваемых курсов в сохранённом живом HTML точно совпали с новым `Course.description`.
