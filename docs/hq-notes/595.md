## PW_PKG_BYTES

npm view запрашивает только метаданные реестра, но стандартный npm пытается записать HTTP-кэш. Первый запрос с npm_config_cache=/dev/null завершился ENOTDIR; npm сообщил, что логи не записаны из-за logs-max=0. Для успешных запросов использована следующая временная функция оболочки: она вызывает установленный npm CLI, меняя только режим HTTP-кэша в памяти процесса на no-store. Файлы npm не изменяются.

```sh
task595_npm_cli=$(command -v npm)
npm() {
  npm_config_cache=/dev/null npm_config_logs_max=0 npm_config_update_notifier=false node -e '
    const fs=require("node:fs"),path=require("node:path");
    const cli=fs.realpathSync(process.argv[1]);
    const fetchPath=require.resolve("make-fetch-happen",{paths:[path.resolve(path.dirname(cli),"..")]});
    const fetch=require(fetchPath);
    require.cache[fetchPath].exports=Object.assign((url,opts)=>fetch(url,{...opts,cache:"no-store",cachePath:undefined}),fetch);
    process.argv=[process.argv[0],cli,...process.argv.slice(2)];
    require(cli);
  ' "$task595_npm_cli" "$@"
}
```
