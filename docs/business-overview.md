# Обзор платформы

Данные собраны из продовой Firestore-базы (проект `ai-video-plat`) на 2026-07-21.

## Что это за продукт

Видео-платформа обучения по подписке: каталог курсов с видео-уроками
(YouTube-эмбеды), часть уроков открыта бесплатно, часть — только по платной
подписке (пейволл). Есть личный кабинет с прогрессом, админка для управления
курсами/уроками/пользователями/подписками, партнёрские реферальные ссылки
с брендингом (`/r/[slug]`) и продуктовая аналитика воронок через PostHog.

Монетизация — через подписки (`manual` / `payment` / `b2b`), доступ выдаётся
либо на все курсы, либо на конкретный список `courseIds`. Есть механизм
pending-грантов: доступ можно выдать на email ещё до регистрации пользователя,
он активируется автоматически при первом входе. Истёкшие подписки снимаются
по крону (`/api/cron/expire`).

## Чему учит платформа

Курс полностью посвящён **работе с Claude Code** — агентным AI-инструментом
для разработки — от установки до продвинутых сценариев с собственными
агентами. По сути это практический курс «AI-ассистированная разработка для
вайбкодеров»: как эксплуатировать Claude Code как основной инструмент
для создания и деплоя проектов, а не просто разово попросить что-то написать.

### Курс 1 — «Claude Code — Свои агенты» (платный, 9 уроков)

1. **Вступление** (бесплатный) — обзорное видео, без конспекта.
2. **Знакомство с Claude Code** — установка (macOS/Linux/Windows), команда
   запуска `claude`, разница моделей Opus/Sonnet/Haiku, понятие скилла.
   ДЗ: создать проект, запустить Claude Code, создать скилл собственного
   голоса (обучить на своих сообщениях, сгенерировать посты).
3. **Усложняем работу. Вайбкодинг — начало** — что такое контекст ИИ и почему
   он не бесконечен; правила гигиены чата (один чат — одна задача, не вести
   долгие сессии, дробить большие задачи на этапы); инструкция про запрет
   записи в глобальную память/пути. ДЗ: сделать HTML-страницу с данными
   через диалог с Claude.
4. **Плагины и скиллы** — конкретные рекомендованные скиллы и плагины
   (`ui-ux-pro-max-skill`, `remotion-dev/skills`, `obra/superpowers`);
   совет ставить только нужные скиллы. ДЗ: улучшить свой сайт скиллами +
   анимация через Remotion, попробовать спланировать фичу через superpowers.
5. **Как работать между проектами** — принцип «1 проект = 1 контекст Claude»,
   кросс-проектный доступ только по явному указанию, команды `/resume`,
   `/usage`, `/model`. ДЗ: создать новый проект и попросить Claude найти
   другой проект.
6. **Как работать с CLAUDE.md** — модульная структура конфигурации
   (`.claude/rules`, `.claude/commands`), команда `/init`. ДЗ: разложить
   существующий CLAUDE.md по отдельным правилам.
7. **MCP** — Model Context Protocol как способ подключать внешние сервисы
   к Claude (в приложении Claude — «connectors»). ДЗ: подключить MCP
   какого-либо сервиса и выполнить через него действие.
8. **GitHub** — GitHub и Vercel как связка для хостинга кода и деплоя сайта;
   как попросить Claude запушить код и задеплоить. ДЗ: задеплоить сайт на
   Vercel и запушить репозиторий на GitHub.
9. **Агенты. Основа** — агенты живут в `.claude/agents`; принцип «один агент —
   одна узкая задача» вместо универсального агента на всё. ДЗ: спроектировать
   и создать собственных специализированных агентов под свои задачи.

### Курс 2 — «Дополнительные материалы» (платный, 5 уроков)

Видео есть у всех, но письменных конспектов (materials) в базе пока нет —
только заголовки:

1. Вступление (бесплатный)
2. Промпт-инжиниринг
3. Парсинг соц.сетей
4. Токены, лимиты
5. Галлюцинации

## Структура доступа

- `access: 'free'` — открыт всем без подписки (обычно вступительный урок курса).
- `access: 'paid'` — требует активную подписку пользователя.
- Курс тоже имеет свой `access`, но реальное разграничение идёт на уровне урока.

## Итог для позиционирования

Это нишевый практический видеокурс не про «ИИ в целом», а конкретно про
Claude Code как ежедневный рабочий инструмент разработчика/вайбкодера:
от установки и базовых команд — через гигиену контекста, скиллы, MCP —
до собственных агентов и деплоя проекта в продакшен (GitHub + Vercel).
Каждый урок заканчивается конкретным домашним заданием, то есть формат —
практикум, а не лекции.
