# Тестовые (маркетинговые) курсы — дизайн

Дата: 2026-08-13

## Цель

Дать возможность выкладывать курсы-пустышки («без реального доступа»,
маркетинговый эксперимент) на витрину сайта, выглядящие как настоящие, чтобы
измерять спрос по кликам, не открывая реальный контент. Плюс — независимая
возможность визуально выделять любые полки курсов (тег у названия и/или
подсветка фона на весь экран).

## 1. Модель данных

Новые поля в `Course` (`src/lib/types.ts`), независимые друг от друга:

```ts
isTest: boolean;                   // курс без реального доступа
testToastMessage: string | null;   // текст тоста при клике (если пусто — дефолт "Курс скоро откроется")
testLandingHtml: string | null;    // сырой HTML лендинга предзаписи, вставляется как есть
showBadge: boolean;                // показать тег рядом с названием курса
badgeText: string | null;          // текст тега; пусто — тег не рендерится, даже если showBadge=true
highlightBackground: boolean;      // подсветка фона на 100% экрана под полкой курса
clickCount: number;                // счётчик кликов по тестовому курсу, default 0
```

Все поля хранятся в Firestore в документе курса (`courses/{id}`), как остальные
поля `Course`.

## 2. Админка

`src/app/admin/courses/[courseId]/page.tsx` + `actions.ts` (`updateCourse`,
`createCourse`) — по образцу существующего чекбокса `published`:

- Чекбокс **«Тестовый курс (без реального доступа)»** → раскрывает два поля:
  «Текст тоста» (input) и «HTML лендинга предзаписи» (textarea).
- Чекбокс **«Показать тег рядом с названием»** → раскрывает поле «Текст тега».
- Чекбокс **«Подсветить фон полки на весь экран»** — без доп. полей,
  фиксированный визуальный стиль.

В списке курсов `admin/courses/page.tsx` рядом с тестовыми курсами
отображается `clickCount`.

## 3. Публичная витрина

`src/components/course-carousel.tsx`:

- если `showBadge && badgeText` — рядом с заголовком курса рендерится
  `<Badge>` (`src/components/ui/badge.tsx`) с этим текстом.
- если `highlightBackground` — секция карусели оборачивается в full-bleed блок
  (100vw через `left: 50%; margin-left: -50vw; width: 100vw`) с ярким
  градиентным/glow-фоном, в стиле существующих `bg-hero-glow` /
  `promo-banner.tsx`.

Оба флага работают независимо от `isTest` и друг от друга — можно выделить и
обычный курс.

## 4. Клик по тестовому курсу

`LessonCard` (`src/components/lesson-card.tsx`) для уроков внутри курса с
`isTest === true` рендерится как клиентский компонент вместо обычной ссылки на
урок:

- `href` ведёт на `/waitlist/[courseId]` вместо страницы урока.
- `onClick`:
  1. `toast(course.testToastMessage || 'Курс скоро откроется')` (sonner,
     `Toaster` уже смонтирован в `src/app/layout.tsx`).
  2. Fire-and-forget вызов нового Server Action `incrementTestCourseClick(courseId)`
     — атомарный `FieldValue.increment(1)` на поле `clickCount` в Firestore.
- Переход по `Link` происходит одновременно с тостом; поскольку `Toaster`
  живёт в root layout и не размонтируется при клиентской навигации, тост
  остаётся виден и после перехода на лендинг.

## 5. Лендинг предзаписи

Новый роут `src/app/(app)/waitlist/[courseId]/page.tsx` (Server Component):

- Читает курс из Firestore по `courseId`.
- Если курс не найден или `isTest === false` → `notFound()`.
- Если задан `testLandingHtml` — рендерит его через `dangerouslySetInnerHTML`
  (доверенный контент: пишется/вставляется владельцем сайта в админке, не
  пользовательский ввод).
- Если `testLandingHtml` не задан — fallback-блок: заголовок курса + текст
  «курс скоро откроется» + кнопка на `start.gelato.su` (по образцу текущих
  `PromoCta`).

## Вне рамок

- Форма сбора email/заявок на лендинге предзаписи — в этой версии не строим.
  Автор сам вставляет в HTML любую ссылку (например на Telegram-бота или
  внешнюю форму). Если понадобится нативная форма — отдельная фича с
  коллекцией `leads` в Firestore.
- Внешняя аналитика (PostHog) не используется для подсчёта кликов — только
  простой счётчик в Firestore/админке.
- Настройка визуального стиля подсветки фона (цвета/градиент) — фиксированный
  вариант, без кастомизации в этой версии.
