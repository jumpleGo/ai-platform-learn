## Разведка и замер

Проверено 2026-11-11: единственный шаблон маршрута —
`src/app/(app)/courses/[courseSlug]/page.tsx`. Данные курсов приходят из
`getPublishedCoursesWithLessons()`, редакторские лендинги — из
`src/lib/course-landings.ts`; для `claude-code` используется fallback.
Отдельные HTML-макеты в `docs/landings` не являются маршрутами приложения.

| Лендинг | Бесплатный CTA до | Бесплатный CTA после | Урок существует |
| --- | --- | --- | --- |
| `vibecoding` | `/courses/claude-code/lessons/4?from=vibe_landing` | тот же | да |
| `claude-code-agents` | `/courses/claude-code/lessons/1?from=course_landing` | `/courses/claude-code-agents/lessons/1?from=course_landing` | до: нет; после: да |
| `ai-cartoons` | отсутствует | отсутствует | неприменимо |
| `claude-code` | отсутствует | отсутствует | неприменимо |

`it-vibecoding` также есть в карте редакторских лендингов и условии JSX.
Если такой курс опубликован, он использует тот же `VibeGuestCta` со ссылкой
на урок 4. Публичный `/courses/it-vibecoding` на момент проверки сам отдаёт
soft-404; это не дополнительный существующий лендинг и не входит в фикс.

Наличие маршрута проверено по
`src/app/(app)/courses/[courseSlug]/lessons/[lessonNumber]/page.tsx` и
`resolveLesson()` в `src/lib/db/courses.ts`: курс должен быть опубликован,
номер указывает на позицию урока до фильтрации, снятые с публикации уроки
дают `null`. Каталог сохраняет те же номера и исключает неопубликованные
уроки. Поэтому номер нельзя заменить индексом в отфильтрованном массиве.

Дополнительный read-only HTTP-замер подтвердил 200 без маркера ошибки у
четырёх лендингов, урока `claude-code/4?from=vibe_landing` и урока
`claude-code-agents/1`. Старый адрес `claude-code/1?from=course_landing`
ответил 200 с `NEXT_HTTP_ERROR_FALLBACK;404`. Наличие редакторского текста
урока 1 в `free-lessons.ts` само по себе не означает, что урок опубликован.

Техническая метрика: **битые ссылки бесплатных CTA: 1 до → 0 после**.
После — результат проверки изменённого JSX по каталогу теста; публикация
на проде в этот замер не входит. Сохранённый `from=course_landing` позволяет
отделять источник переходов; продуктовый эффект и `retention_w1` требуют
отдельного PostHog-замера после выкладки, с базой #50 и выдержкой минимум 72 ч.

## Причина и изменение

ROOT_CAUSE: общий шаблон использовал литерал с устаревшим адресом урока 1
курса-хаба вместо слага и уроков текущего курса. Кнопка с этим литералом
показывалась только на лендинге агентов. Рабочую ссылку вайбкодинга на урок 4
задаёт отдельный `VibeGuestCta`.

Теперь ссылка агентов собирается через существующие `courseKey(course)` и
`lessonPath(key, firstFreeLesson.number)` из первого бесплатного урока
опубликованного каталога, с сохранением `?from=course_landing`. При отсутствии
бесплатного урока кнопка не предлагает несуществующий адрес.

SOFT404_CAUSE: `LessonPage` вызывает `notFound()` после `await getSession()`
и `await resolveLesson()`. `lessons/[lessonNumber]/loading.tsx` создаёт
Suspense-границу; уже начавшийся стрим отправляет заголовок HTTP 200.
После этого Next.js сообщает 404 в содержимом, но не может изменить статус.
Это описано в установленной документации Next.js 16.2.9:
`node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/not-found.md`
и `loading.md`, раздел Status Codes. Поведение soft-404 не изменено.

## Регрессия

Добавлен `tests/course-landing-links.test.ts` по требованию задачи: он
проверяет ссылки из фактического JSX всех четырёх лендингов и кодового
варианта `it-vibecoding`, раскрывая настоящий `VibeGuestCta`. Firestore и
побочные зависимости заменены фикстурой опубликованного каталога; это
локальная регрессионная проверка, а не чтение прод-БД. Async-функция страницы
вызывается напрямую, без попытки рендерить async RSC через Vitest.

Перед изменением страницы финальная версия теста дала exit 1: 2 failed,
4 passed. Проверка существования урока упала именно на старой ссылке
`/courses/claude-code/lessons/1?from=course_landing`. Дополнительная проверка
требует номер 5 из данных при платном уроке 2 и проверяет отсутствие кнопки
при пустом списке. Существующие тесты и скрипты метрик не менялись.

После исправления выполнено
`export PATH=$HOME/.local/node/bin:$PATH && npx tsc --noEmit -p . && npx vitest run`:
TypeScript exit 0; Vitest exit 0, 17 файлов и 138 тестов прошли, включая все
6 новых проверок. Изменены только шаблон лендинга, новый тест и этот отчёт.
