# Отчёт: воронки и точки утечки (29.09–10.10 vs всплеск 17–18.09)

Источник: sessions.jsonl (PostHog, проект 259690), проверки HogQL. Основной период 29.09–10.10: **2309 сессий, 2211 пользователей**. Всплеск 17–18.09: **3004 сессии, 2870 пользователей**.

## 0. Главный вывод

1. **Платных конверсий за 29.09–10.10 нет.** `tariff_selected`/`subscribe_clicked` — 3 сессии (0,3% от 977 видевших лендинг курса), `payment_started` — 0, `subscription_activated` — 0. Две регистрации (`signup_completed`, 30.09) — люди из /guide, искавшие «вход», ничего не купили. Две оплаты 17.09 — тестовые (owner-email, цена «10₽», VN/Mac).
2. **Воронка /guide технически не ведёт к курсу.** Страница редиректит в PDF через ≤1,5 с, ссылки на курс на ней нет, возврат «назад» из PDF снова редиректит (ловушка). На iOS редирект, похоже, часто не срабатывает в in-app браузере Instagram: 350 из 680 iOS-сессий — 0 с без единого события, fallback-клик всего 14 (2%) против 122 (22%) на Android.
3. **На лендинге vibecoding 46% доходят до тарифов и 0,7% из них жмут «Оформить».** Это ценовой/доверительный барьер, не проблема внимания: медиана после `pricing_viewed` — 16 с, 43% уходят в течение 10 с после показа цены.

## 3. Где теряются люди

Абсолют (29.09–10.10):
1. **/guide: 1261 → 123 дошли до курса (−1138, −90%)**. Страница-редирект без ссылки на курс.
2. **vibecoding: 815 входов → 373 pricing (−442, −54%)**. Скролл при уходе равномерный от 0 до 1 (~40–50 на десятую) — нет одного «обрыва»; 105 сессий 0 с, 167 <5 с.
3. **pricing_viewed 447 → «Оформить» 3 (−99,3%)**. Самый большой процентный провал. 43% уходят ≤10 с после цены.
4. **Урок: 84 → 14 video_start (−83%)**.
5. **Модалка: 3 → 0**.

По дням: 30.09 (1674 сессий, 81% single, pricing 17%, 2 «Оформить», 17 TG, 115 PDF-fallback); 01.10 (215, pricing 7%, медиана 1 с — хвост /guide); 02–06.10 (42–92/день, почти весь трафик — vibecoding из link_in_bio, pricing 28–44%, медиана 28–46 с, «Оформить» 0). Хвост вовлечённее всплеска, но оплата тоже 0. С 08.10 входы только на главную (10–15/день).

Источники: все 2162 сессии с utm — `ig/null` (campaign не размечен); `$direct` 152 (медиана 2 с). Различить пост/сторис/рилс нельзя, только `utm_content=link_in_bio`.

Устройства: Mobile 96%. **iOS 1239 сессий, медиана 1 с; Android 996, медиана 56 с** — разница из-за /guide. На vibecoding `pricing_viewed`: iOS 22%, Android 16%.

Страны: DE 360, NL 299, US 203, RU 140, KZ 103 — нигде «Оформить» >1; UZ (71) и KG (41) чаще идут в TG (по 3).

Новые vs вернувшиеся: >1 сессии — 83 пользователя (3,8%), в разные дни — 37 (1,7%); gap медиана 1 день (22 из 37 — на следующий день, 8 — через 2–3, 7 — позже). Но 58 из 81 вторых визитов — `/guide > /guide` (ловушка редиректа), 12 — повторно vibecoding. Вернувшиеся: 104 сессии, pricing 8, «Оформить» 0, TG 0. **Возвратов «подумать и купить» нет.**

## 4. Корректность трекинга

| Проблема | Факт | Последствие |
|---|---|---|
| Скачивание PDF не пишется в PostHog | /guide: `window.location.replace` через ≤1,5 с, цель только в Метрике; в PostHog — fallback-клик (136) | Нельзя посчитать гайд→курс; iOS «0 с» неотличим от отказа |
| Двойные PV /guide | 104 сессии (8%), 61 — ровно два PV; интервалы 300–1500 с | Не дубль, а возврат «назад» из PDF и повторный редирект; раздувает PV и «вернувшихся» |
| Дубли PV на лендингах во всплеске | 356 сессий (12%) 17–18.09, 59 — в пределах 2 с | TikTok/Pangle авто-перезагрузка; вовлечение по PV завышено |
| Сессии без leave и кликов | 775 (34%) основной, 963 (32%) всплеск | In-app не шлёт `$pageleave`; scroll известен для 66% |
| «Личка» без `telegram_click` | 18 из 18 | TG-конверсия с лендинга видна только через autocapture |
| «Выбрать тариф» без `tariff_selected` | 32 из 34 — это якорь к #pricing | `tariff_selected` фактически = клик «Оформить», дублирует `subscribe_clicked` (всегда парой; prop `tariff` null, пишется `tariffId`) |
| `subscribe_clicked` дважды на один сабмит | `payment-modal.tsx:170` и `course-buy-button.tsx:29` | Завышение ×2 при реальной оплате (видно 17.09) |
| «К тарифам» без `pricing_viewed` | 14 из 80 | Проверить порог IntersectionObserver после якоря |
| PV урока без `lesson_view` | 4 | допустимо |
| Внутренние события на проде | `instrument_opened`, `timeframe_changed`, `session_start` (/charts), 10+ сессий | фильтровать по `$pathname` |
| `utm_campaign` пуст у всего ig-трафика | 2162 сессий | не отличить пост/сторис/рилс |
| Тестовые оплаты в проде | 17.09: owner-email, «10₽», `trial_activated` в `subscription_activated` | исключать тестовые distinct_id / `price<100` |
| Чужой хост | `monitoring.moneyflowzen.ru/login` в том же проекте | фильтр по `$host` |

## 5. Рекомендации

### (b) /guide — приоритет 1 (1261 сессии, 90% в никуда)
1. **Убрать авторедирект: /guide = страница с кнопкой «Скачать PDF» + блок «Что дальше: бесплатный урок / курс».** Ожидание: переход на курс с 9,8% до 25–35% (123 → ~350 при том же трафике), исчезновение ловушки «назад».
2. Если редирект оставить — `<a download>`/новая вкладка вместо `replace` и ссылка на курс на странице; проверить открытие PDF в iOS Instagram-браузере.
3. События: `guide_pdf_click`, `guide_view` с `os`/`in_app`.
4. A/B `guide_page_layout`: `redirect` vs `landing`. Primary — PV /courses/* в сессии; secondary — `pricing_viewed`. ~300 сессий на вариант — один пост.
5. В PDF — ссылка на урок/курс с `utm_source=pdf` (сейчас 157 из 185 переходов — через био).

### (a) лендинг → оплата — приоритет 2 (99,3% уходят после цены)
1. Проблема — цена/доверие. A/B `vibe_pricing_offer`: control vs «помесячно/рассрочка» vs «первый модуль за X ₽ + возврат 7 дней». Primary — уникальные `subscribe_clicked`, secondary — `payment_started`. При 3 кликах/2 недели не досчитается — сперва поднять базу через /guide.
2. Модалка: 3 из 3 закрыли форму. Убрать обязательный Telegram, оставить один email, согласие — текстом. События `payment_modal_opened/closed` с `fields_filled`.
3. TG как «мягкая» конверсия под тарифами («Не готовы решить? Напишите, подберём формат»). A/B `pricing_secondary_cta`: none vs tg_link. Primary — `telegram_click`+`subscribe_clicked`. Ожидание: ×2 контактов (1,2% → ~2,5%).
4. `vibe_hero_copy`: pricing-rate control 52%, salary 50%, keywords 44%, both 38% (n≈200) — `both` хуже; `vibe_landing_blocks`: why 55%, base 53%, cycle 49%, program 33% (n≈118) — `program` вредит. Закрыть оба, зафиксировать control/base; не плодить тесты верха воронки, пока низ = 0.
5. «Выбрать тариф» → «Смотреть тарифы» (это якорь); `tariff_selected` — только при выборе карточки в модалке; убрать дубль `subscribe_clicked` в модалке.

### (c) бесплатный урок
1. 84 → 14 стартов видео. На lessons/4 CTA выше плеера ловит клики при scroll 0,2 (11 из 18 до старта видео). **Primary-CTA под видео, показывать после `video_25`.**
2. Крупная превью-кнопка/автозапуск mute; событие `video_impression`.
3. A/B `lesson_cta_position`: above vs below_after_25. Primary — `video_25`; secondary — `pricing_viewed` после CTA. Ожидание: video_start 16% → 30%+.
4. CTA с урока — на `#pricing` с `source=free_lesson` (из 17 переходов только 6 дошли до прайсинга).

### (d) главная/квиз
1. Результат квиза вести на урок 4 (единственный с CTA) или на `#pricing` с персональным заголовком; событие `quiz_result` с `answer`.
2. 60% без квиза уходят; «Бесплатно» (34 клика) — главный CTA. Низкий приоритет (193 входа за 12 дней).

### Трекинг (до следующего поста)
- `guide_pdf_click`, `telegram_click` на все TG-ссылки (с `place`), `payment_modal_opened/closed`, `video_impression`.
- `utm_campaign` в ссылках Instagram: `bio`, `story_<date>`, `reels_<id>`.
- Фильтры в инсайтах: `$host = gelato.education`, `$pathname not like '/charts%'`, исключить тестовые distinct_id и `price < 100`.
- Для iOS in-app смотреть покрытие `$pageleave` по ОС; при <50% не использовать scroll-метрики для iOS.
