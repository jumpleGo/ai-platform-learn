## 3. A/B-тесты

Отчёт `ab-report.mjs`: free_cta lesson_view 0,6% vs 9,0% (P=100%); blocks base 39,6%, program 26,6% (P=0,4%), audience 32,6% (8,4%), остальные 37–40%; hero control 39,9%, both 29,9% (P=0,5%); lesson_quiz_banner 11/11 — ничего.

Проверки:
- SRM нет: free_cta 651/607 (χ²=1,54, df=1), hero 326/322/314/296 (χ²=1,69, df=3), blocks 192…168 (χ²=1,89, df=6). Пользователей с двумя вариантами 0–2.
- Перекос из-за всплесков: все три теста лендинга — одна популяция (1258 сессий / 1222 пользователя), из них 288 (23%) — TikTok 17–19.09 с 1–6% pricing_viewed. Распределены равномерно, знак не меняют, но занижают абсолюты (~39% в отчёте против 48–50% на IG) и съедают мощность. Пересчёт только IG 29.09+ по пользователям:
  - free_cta: control n=462 pricing 47,0%, lesson 5; free_lesson n=437 pricing 45,1%, lesson 49, video_start 11, video_50 7.
  - hero: control 49,5% (208), keywords 48,5% (241), salary 48,9% (235), both 36,7% (215); z(control vs both)=2,6.
  - blocks: why 52,2% (113), proof 51,2% (121), base 49,6% (129), cycle 49,3% (140), author 46,0% (137), audience 41,7% (127), program 33,3% (132); z(base vs program)=2,65.
- Эффект новизны не применим: аудитория каждого всплеска новая (возвратов <4%).
- Главный перекос: 73% экспозиций собраны за 48 часов одной аудиторией одного креатива — это кластер, а не независимая выборка; гипотеза hero про «холодного человека из Threads» проверена на тёплых подписчиках IG. tariff_selected/payment_started (0–2 на вариант) при ~0,3% базе требуют десятков тысяч экспозиций.
- blocks×hero: ячейки 27–66, паттернов кроме минуса у both и program нет (ненадёжно).

Рекомендации (решение за пользователем):
1. free_cta — закрывать в пользу free_lesson: lesson_view ×10, pricing_viewed не просел.
2. hero — закрывать как «both проигрывает»; control/keywords/salary неразличимы (48–50%), 4 варианта при ~300/вариант за месяц 2–3 п.п. не разрешат.
3. blocks — снимать program и audience; среди why/proof/base/cycle разницы нет (SE≈4,4 п.п.). Либо схлопнуть до base/why/proof и перезапустить, либо взять base по принципу «короче не хуже» и идти к ступени 2.
4. Исключить из ab-report экспозиции с utm_source=tiktok/pangle — занижают все проценты на ~10 п.п.
5. minExposuresPerVariant=60 ловит только эффекты >15 п.п.; пересчитать под реальный трафик.
6. lesson_quiz_banner — 10–20 сессий в уроки/неделю, не наберётся; снять или принять compact по UX.
7. Добавить в ab-report χ² SRM и разбивку по источнику.

## 5. Рекомендации по трафику
- Масштабировать: подписчики Instagram через шапку профиля — единственный источник с ~45% до цен. Платный TikTok-автотаргет по СНГ/ЮВА не повторять; если платное — только гео DE/NL/US/PL/RU/KZ, посадка на лендинг, сравнивать с органикой по pricing_viewed.
- Лид-магнит дал ×3 кликов, но 4% до цен и ни одного контакта (редирект на PDF). Сделать страницу «гайд + CTA в урок/лендинг + Telegram» или выдачу PDF по кнопке; на Android авторедирект не работает.
- Посадочная для продажи — /courses/vibecoding. Главная `/` как посадочная: 49% многостраничных, но 6% до цен — уводит в квиз и /free. Кросс-ссылку на гайд с лендинга (42 перехода) ставить после тарифов.
- UTM: разные ссылки на каждый пост — `utm_campaign=<дата/тема>`, `utm_content=story|reel|bio|post`; сейчас креатив восстанавливается только по часам. Для платного — обязательные campaign-названия (6 сессий с `__CAMPAIGN_NAME__`).
- Аналитика: событие `guide_downloaded` в PostHog (+ различать авторедирект/клик), `payment_method_clicked` (карта/крипта/Telegram) с country и tariff, `tariff_modal_closed`; исключать внутренние сессии (VN + Mac/Windows, /charts, test_rub); на iOS добавить события видимости блоков (hero_viewed, program_viewed) вместо опоры на $pageleave; фильтр по источнику и SRM в ab-report.
