# Список покупок
Учебная программа: добавляет товар в список и печатает список.

## Запуск и проверка
Нужны Node.js и npm. Сторонних пакетов нет, установка пакетов не нужна.
Запуск: npm start. Проверка: npm test. Отдельной сборки нет.

## Где что лежит
list.mjs — добавление товара; app.mjs — вывод на экран.
check.mjs — проверки; package.json — команды запуска.
Правила списка держи в list.mjs, вывод — в app.mjs.

## Как работает список
Товар — строка с названием. addItem(items, name) возвращает новый список.
Прежний список не меняется. Пробелы по краям убираются, пустое имя пропускается.
Пример: addItem(['хлеб'], ' молоко ') возвращает ['хлеб', 'молоко'].

## Правила работы
Сохраняй стиль файлов: одинарные кавычки и точки с запятой.
Не подключай сеть и сторонние пакеты. Не добавляй пароли и ключи.
После правки запусти npm test и сообщи результат. Если не запускал, скажи об этом.
При изменении команды, имени файла или поведения обнови этот CLAUDE.md вместе с кодом.
