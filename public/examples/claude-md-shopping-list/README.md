# Список покупок: пример к статье о CLAUDE.md

Нужны Node.js и npm. Официальная установка: https://nodejs.org/.
Сторонних пакетов нет. Команда установки пакетов не нужна.

Распакуйте архив, откройте терминал в папке `claude-md-shopping-list`:

```sh
npm start
npm test
```

Первая команда выводит «хлеб» и «молоко» на отдельных строках.
Вторая проверяет добавление товара, пустое название и сохранность прежнего списка.
Программа не обращается к сети и не сохраняет покупки на диск.

Для сравнения инструкций прочитайте `CLAUDE.md`. Вариант без чек-листа:

```text
Это список покупок. Пиши понятный код и проверяй изменения.
```

Сравните, понятно ли из каждого варианта, где менять поведение, как его проверить
и что делать с пустым названием. Это сравнение содержания инструкций, не замер
качества работы ИИ. Доли из исследования к этому проекту не относятся.

Статья: https://gelato.education/blog/claude-md-primer-chek-list
